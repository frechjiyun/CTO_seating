# 🪑 CTO Class Seating — 강의실 좌석 배치 & 출결 관리

실시간 강의실 좌석 배치도 및 출결 관리 웹앱입니다.  
Firebase Realtime Database 기반으로 여러 학생이 동시에 접속해 착석할 수 있습니다.

---

## 🔗 바로 접속

| 용도 | URL |
|------|-----|
| 👨‍🏫 강사 | [https://frechjiyun.github.io/CTO_seating/index.html?mode=admin](https://frechjiyun.github.io/CTO_seating/index.html?mode=admin) |
| 🎓 학생 | 강사가 저장 후 생성된 URL을 공유 (`?mode=student&course=교과목코드&date=날짜` 포함) |

> 학생 URL은 강사가 날짜와 교과목 코드를 저장하면 자동으로 생성됩니다.

---

## 주요 기능

- **실시간 좌석 배치** — 학생이 자리를 클릭하거나 명단에서 드래그해서 착석
- **출결 자동 판정** — 강의 시작 시간 기준 1시간 이후 지각, 3시간 이후 결석 처리
- **출결 정리 리포트** — 결석생, 지각생, 미확인 명단 자동 생성 및 복사
- **교과목별 데이터 분리** — 교과목 코드 기준으로 Firebase 경로 자동 분리
- **날짜별 기록 보존** — 날짜마다 독립적으로 저장되어 과거 기록 재조회 가능
- **명단 업로드** — CSV / Excel / PDF 출석부 파일로 수강생 명단 등록
- **강사 비밀번호** — 강사 모드 접근 시 비밀번호 인증

---

## 사용법

### 강사

1. `?mode=admin` URL로 접속 후 비밀번호 입력
2. **강사 설정** 입력 (교과목 코드, 과목명, 날짜, 요일, 시작/종료 시간, CTO)
3. **💾 저장 & 학생 URL 생성** 클릭
4. 생성된 학생 URL 복사 후 학생들에게 공유
5. 수업 종료 후 **🔒 수업 마감 & 출결 정리 생성** 클릭
6. 출결 리포트 복사 후 활용

> 교과목 코드, 과목명, 요일, 시작/종료 시간은 한 번 저장하면 다음 접속 시 자동으로 채워집니다.

### 학생

1. 강사가 공유한 URL로 접속 (학생 모드 자동 진입)
2. 좌석 클릭 또는 오른쪽 명단에서 이름을 드래그해서 자리에 놓기
3. 착석 즉시 Firebase에 저장되며 강의 시작 시간 기준 출결 상태 표시

## URL 구조

| 용도 | URL 형식 |
|------|----------|
| 강사 | `index.html?mode=admin` |
| 학생 | `index.html?mode=student&course=교과목코드&date=날짜` |

**과거 기록 조회** (강사 모드):  
날짜 입력란에 과거 날짜를 입력하고 저장하면 해당 날짜 데이터로 전환됩니다.

---

## Firebase 데이터 구조

```
교과목코드/
  adminPw          ← 강사 비밀번호 (과목 단위)
  roster           ← 수강생 명단 (날짜 무관 공통)
  날짜/
    meta           ← 강의 정보 (날짜, CTO, 시간 등)
    closed         ← 마감 여부
    seats/
      1-1-1        ← { name: "홍길동", time: 1234567890 }
      1-2-1        ← ...
```

|------|------|

| ⏰ 지각 | 강의 시작 후 1시간 ~ 3시간 사이 착석 |

## 배포

**Netlify (권장)**

1. [app.netlify.com](https://app.netlify.com) 접속
2. `index.html` 파일 드래그 앤 드롭
3. 배포 완료 후 URL 확인

**파일 업데이트**  
Netlify 대시보드 → Production deploys 영역에 새 `index.html` 드래그 앤 드롭

---

## 여러 강사가 같은 파일을 사용할 경우

같은 `index.html`을 공유해도 **교과목 코드가 다르면 데이터가 완전히 분리**됩니다.  
단, Firebase 프로젝트는 동일하게 공유합니다. 완전히 독립된 환경이 필요하다면 각자 Firebase 프로젝트를 생성하고 `firebaseConfig` 값을 교체하세요.
