# 🪑 좌석 배치도 — CTO Class Seating

Firebase 실시간 DB 기반 강의실 좌석 배치 & 출결 관리 웹앱입니다.

---

## 시작하기

### 강사 (admin)

1. URL 뒤에 `?mode=admin` 붙여서 접속
   ```
   https://your-url/index.html?mode=admin
   ```
2. 하단 **강사 설정** 패널에서 날짜, 요일, 시작/종료 시간, CTO 입력
3. **💾 저장 & 학생 URL 생성** 버튼 클릭
4. 생성된 학생 URL을 수강생들에게 공유

### 학생 (student)

1. 강사가 공유한 URL(`?mode=student`)로 접속
2. 빈 자리 클릭 → 이름 입력 후 **앉기**
   또는 오른쪽 명단에서 이름을 드래그해 원하는 자리에 드롭

---

## 주요 기능

| 기능 | 설명 |
|------|------|
| 실시간 동기화 | Firebase Realtime DB로 모든 접속자에게 즉시 반영 |
| 드래그 & 드롭 | 명단에서 자리로 드래그해 배치 |
| 출결 자동 판정 | 강의 시작 기준 1시간 이후 → 지각 / 3시간 이후 → 결석 |
| 수업 마감 | 마감 후 출결 정리 텍스트 자동 생성 및 복사 |
| 좌석 초기화 | 강사가 전체 좌석 한 번에 초기화 가능 |

---

## 출결 기준

- ✅ **출석**: 강의 시작 후 1시간 이내 착석
- ⏰ **지각**: 강의 시작 후 1시간 ~ 3시간 사이 착석
- ❌ **결석**: 강의 시작 후 3시간 이후 착석 또는 미착석

---

## 기술 스택

- Firebase Realtime Database (실시간 동기화)
- Vanilla JS (ES Modules)
- HTML/CSS (다크모드 지원)
